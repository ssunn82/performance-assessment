# 中层绩效考核系统

面向企业中层管理人员的**多季度绩效考核系统**：支持多季度会话管理、Excel 批量导入、二维码扫码打分、加权自动计分、结果导出，并带登录保护的管理后台；考核任务可配置**生命周期状态机**，管理员可**重置考核人打分并保留归档记录**。纯 FastAPI + SQLite + Jinja2 实现，**零外部服务依赖**，可单机 / NAS / 轻量云服务器部署。

## 功能特性

- **多季度会话**：一个系统管理多个考核周期，互不干扰
- **三类基础数据**：考核人、被考核人（含职务/部门/组别/部门参考分）、考核指标（名称+权重+满分）
- **Excel 友好**：提供导入模板下载、批量导入、结果导出（含工号，不含部门参考分）、二维码 Excel 导出
- **扫码打分**：为每个被考核人生成二维码，考核人手机扫码即可打分；说明文字支持富文本（字号/颜色/加粗/表格等），仅显示在打分首页
- **加权自动计分**：按指标权重汇总，实时进度与最终排名
- **登录保护**：管理后台需账号登录；打分页保持免登录，扫码即用
- **移动端适配**：所有页面响应式，手机操作友好
- **生命周期管理**：每个考核任务支持 `草稿 → 测试 → 运行中 → 暂停 → 结束` 状态流转
  - 草稿/暂停/结束状态下，打分页自动锁定，考核人无法提交
  - 测试模式下仅内部验证打分流程，可一键清空测试数据或保留后正式启动
  - 「结束」为终态，锁定全部打分，保证结果不可再被篡改
- **打分重置与归档**：管理员可在运行中重置某考核人的打分状态（退回待提交），系统自动**快照归档其原打分记录**，保留完整历史可供追溯与查看，考核人可重新打分提交

## 本地运行

```bash
pip install -r requirements.txt
python run.py
# 访问 http://localhost:8000
```

默认账号：`admin` / `admin123`（首次登录请到「系统设置」修改密码）。

## 生产部署（轻量应用服务器 / 云主机）

详见 `deploy.sh` + `nginx.conf` + `gunicorn.conf.py`，三步完成：

```bash
# 1. 上传本项目到服务器并解压，进入目录
# 2. 赋权并执行一键部署
chmod +x deploy.sh
sudo ./deploy.sh
# 3. 在云控制台防火墙放行 TCP 80（及 443 若启用 HTTPS）
```

部署要点：

| 项 | 说明 |
|----|------|
| 运行方式 | `gunicorn -c gunicorn.conf.py main:app`（多 Worker，替代开发服务器） |
| 会话密钥 | 必须通过环境变量 `SESSION_SECRET_KEY` 设置强随机值（见 `.env.example`） |
| 数据库 | SQLite 已开启 WAL 模式，支持多人并发读写 |
| 反向代理 | nginx 反代 `127.0.0.1:8000`，静态资源直出 |
| HTTPS | 强烈建议：HR 数据务必加密传输，用 certbot 免费证书 |
| 进程管理 | systemd 服务，开机自启 + 崩溃自动重启 |
| 备份 | 定期备份 `data_v2.db`（及 `*-wal`/`*-shm` 文件），或利用服务器快照 |

## 生命周期与打分重置

**生命周期状态机**（`assessment_sessions.lifecycle` 字段）流转规则：

| 状态 | 含义 | 考核人能否打分 |
|------|------|----------------|
| `草稿 draft` | 配置阶段，尚未开放 | 否（打分页锁定） |
| `测试 testing` | 内部试运行，验证流程 | 是（仅内部验证） |
| `运行中 running` | 正式考核进行中 | 是 |
| `暂停 paused` | 临时中止 | 否（打分页锁定） |
| `结束 ended` | 考核完成，终态 | 否（全部锁定，结果封存） |

- 从 `测试` 正式启动时，可选择「清空测试数据」或「保留测试数据」。
- `结束` 为不可逆终态，一旦结束所有打分锁定，确保结果不被二次篡改。

**打分重置**：在「进度」页点击某考核人的「重置」按钮，系统会：
1. 将当前打分快照写入 `score_history` 归档表（记录 `archived_at` 批次时间）；
2. 将该考核人退回「待提交」状态，原分数预填回表单；
3. 管理员可在同页「查看记录」追溯每次重置的归档明细。

## 项目结构

```
main.py              FastAPI 主应用（路由 / 鉴权 / 导入导出 / 生命周期 / 重置）
database.py          SQLite 数据层（WAL 模式 / 盐值密码哈希 / score_history 归档）
run.py               本地开发启动入口
gunicorn.conf.py     生产 WSGI/ASGI 配置
nginx.conf           Nginx 反代站点配置
deploy.sh            Ubuntu 一键部署脚本
requirements.txt     Python 依赖
test_e2e.py          端到端测试（77 项，覆盖生命周期流转与打分重置）
部署指南.md          轻量服务器部署详解（防火墙 / HTTPS / 运维命令）
templates/           页面模板（登录 / 后台 / 打分 / 进度 / 结果 / 设置）
static/              前端资源（CSS / JS）
```

## 安全提示

- 管理后台有登录，但**打分页面按设计免登录公开**（方便扫码），请务必配合 HTTPS + 强会话密钥使用
- 默认管理员密码 `admin123` 仅为初始值，上线前必须修改
- 绩效考核属敏感 HR 数据，建议部署在受控网络或启用 HTTPS 的内网/专线环境
